# Специальные вопросы конечно-элементного моделирования двигателей внутреннего сгорания

Учебные материалы по численному моделированию инженерных задач на **Python** с использованием **Jupyter Notebook** и **Gmsh**. В ходе семинаров последовательно рассматриваются построение конечно-элементной модели, формирование элементных и глобальных матриц, задание граничных условий, решение систем уравнений и анализ результатов. Примеры включают стержневые системы, теплопроводность и напряжённо-деформированное состояние деталей.

## Примечания по запуску

Материалы представлены в формате `.ipynb`. Для семинаров с геометрией используются исходные CAD-файлы в каталогах `_geom`; для третьего семинара также приложены подготовленные данные сетки в `_mesh`. Некоторые примеры вводного и дополнительного разделов обращаются к внешним экспериментальным данным, видео или файлам моделей, которых нет в архиве, поэтому для их полного воспроизведения потребуются соответствующие исходные файлы.

Семинар 06 пока не включён в репозиторий и добавлен в таблицу как запланированная работа.
